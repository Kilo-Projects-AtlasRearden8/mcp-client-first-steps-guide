# MCP Client First Steps — Beginner Manual

Welcome. This manual walks you through MCP clients in plain English, step by step, never condescending — like a friend would explain it.

You will learn:

1. **What MCP clients do** (`01-what-is-an-mcp-client.md`)
2. **Connecting an MCP client to local files and folders** (`02-connecting-local-files-folders.md`)
3. **Running your first stdio MCP server** (`03-running-first-stdio-server.md`)
4. **Safety rules for letting an AI access your files** (`04-safety-rules.md`)
5. **Step-by-step checklists** (`checklists/`)
6. **Glossary** (`glossary.md`)

A static HTML version of this manual lives in `site/`. Open `site/index.html` in any browser — no install needed.

## How to use this manual

- Read in order. Each section builds on the last.
- Try the example stdio server in `examples/stdio-server/`. It runs with Node.js and nothing else to install.
- Work through the checklists as you go — check off each step as you complete it.
- No secrets, API keys, or personal data are needed for any of the examples.
